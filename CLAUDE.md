# Bookish Etsy Shop — Working Notes for Claude

## What this project is
Planning and launch workspace for a book-themed Etsy shop. Source of truth for the
shop's concept is `shop-brief.md` — read it before doing any work.

## Folder map
- `shop-brief.md` — concept, audience, product lines, goals (start here)
- `research/` — niche, competitor, and keyword research
- `brand/` — name, voice, visual identity
- `products/` — one file per product (specs, materials, suppliers)
- `listings/` — Etsy listing drafts (title, tags, description, photos)
- `pricing/` — cost breakdowns and price decisions
- `launch-checklist.md` — what's done / what's left

## How to work here
- Keep files in Markdown. One product per file in `products/` and `listings/`,
  named with the same slug (e.g. `products/annotation-tabs.md` ↔ `listings/annotation-tabs.md`).
- Etsy constraints: titles ≤ 140 chars, 13 tags max, each tag ≤ 20 chars.
- Never use copyrighted book titles, quotes, character names, or author names in
  products or tags without confirming they're public domain or licensed.
- When numbers change (costs, fees, prices), update `pricing/` first, then listings.
- Update `launch-checklist.md` when a task is finished.
